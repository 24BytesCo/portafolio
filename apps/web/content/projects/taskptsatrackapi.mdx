## Resumen
- API para crear tareas, categorizarlas y establecer fechas límite.
- Estructura por capas: API, Domain y Application.
- Código fuente: https://github.com/24BytesCo/TaskPtSatrackApi

## Características
- Endpoints para CRUD de tareas y categorías.
- Separación clara entre dominio y lógica de aplicación.

## Stack Técnico
- Lenguaje/plataforma: C# y .NET.
- Arquitectura: N‑capas con Domain/Application/API.

## Implementación
- API como borde de comunicación; Application contiene casos de uso; Domain define entidades y reglas.

## Cómo funciona
- Onboarding: registro/inicio de sesión (si aplica).
- Gestión: creación/edición/listado con validaciones.
- Integraciones: servicios externos cuando corresponde.

## Retos
- Escalabilidad y mantenibilidad del código.
- Seguridad y manejo de datos.
- Experiencia de usuario consistente.

## Mejoras futuras
- Métricas/observabilidad y pruebas más profundas.
- Automatizaciones de despliegue y calidad.
- Nuevas funcionalidades a partir del feedback.
