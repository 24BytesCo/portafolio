## Resumen
- TaskFlowManager API: usuarios, roles y WorkTasks con autenticación JWT.
- Despliegue de referencia en Heroku; Dockerfile y compose para contenedores.
- Código fuente: https://github.com/24BytesCo/PruebaTecnica-DVP-Net-Kubernetes

## Características
- Gestión de usuarios/roles; endpoints para tareas.
- Middleware, filtros y Dtos; colección Postman incluida.

## Stack Técnico
- ASP.NET Core (C#), autenticación JWT.
- Docker y docker‑compose; opcional orquestador (Kubernetes).

## Implementación
- Controllers/Services/Models; migraciones y configuración por entorno.

## Cómo funciona
- Onboarding: registro/inicio de sesión (si aplica).
- Gestión: creación/edición/listado con validaciones.
- Integraciones: servicios externos cuando corresponde.

## Retos
- Escalabilidad y mantenibilidad del código.
- Seguridad y manejo de datos.
- Experiencia de usuario consistente.

## Mejoras futuras
- Métricas/observabilidad y pruebas más profundas.
- Automatizaciones de despliegue y calidad.
- Nuevas funcionalidades a partir del feedback.
