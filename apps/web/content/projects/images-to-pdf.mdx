## Qué hace

Seleccionas varias imágenes, las ordenas y descargas un único PDF. Todo ocurre en el navegador: los archivos nunca salen del equipo, así que sirve para documentos con datos personales o de clientes.

## Por qué existe

Las herramientas en línea para esto suben los archivos a un servidor de terceros. Esta no tiene servidor: es HTML y JavaScript servidos como estáticos desde GitHub Pages, sin cuentas, sin límites artificiales y sin publicidad.

## Detalles

- Conversión y unión en el cliente con generación del PDF en memoria.
- Reordenamiento de páginas antes de exportar.
- Código abierto en GitHub.
