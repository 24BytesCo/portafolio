## Resumen
- API de punto de venta en .NET con proyectos: Api, Application, Domain, Infrastructure, Utilities y Test.
- Contenerizada con Docker (Dockerfile presente).
- Código fuente: https://github.com/24BytesCo/PuntoDeVentaBack

## Características
- Separación por capas para mantener el dominio aislado.
- Utilidades compartidas y proyecto de pruebas.
- Preparado para integrarse con persistencia y servicios externos.

## Stack Técnico
- Lenguaje/plataforma: C# y .NET.
- DevOps: Docker (Dockerfile) para empaquetado y despliegue.

## Implementación
- Proyectos: `PuntoDeVentaBack.Api`, `.Application`, `.Domain`, `.Infraestructure`, `.Utilities`, `.Test`.
- Principios SOLID y organización por responsabilidades.

## Cómo funciona
- Onboarding: registro/inicio de sesión (si aplica).
- Gestión: creación/edición/listado con validaciones.
- Integraciones: servicios externos cuando corresponde.

## Retos
- Escalabilidad y mantenibilidad del código.
- Seguridad y manejo de datos.
- Experiencia de usuario consistente.

## Mejoras futuras
- Métricas/observabilidad y pruebas más profundas.
- Automatizaciones de despliegue y calidad.
- Nuevas funcionalidades a partir del feedback.
