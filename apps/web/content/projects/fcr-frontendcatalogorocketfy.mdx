## Resumen

- SPA Angular para navegar un catálogo (relojes) con autenticación y rendimiento optimizado.
- Despliegue configurado en Firebase Hosting.
- Código fuente: https://github.com/24BytesCo/FCR-FrontEndCatalogoRocketfy

## Características

- Login seguro y rutas protegidas.
- Lazy loading de módulos y componentes críticos.
- Paginación, búsqueda y filtros en el catálogo.
- Modularización del código (core/shared/features).

## Stack Técnico

- Framework: Angular CLI 16.
- Lenguajes/tecnologías: TypeScript, SCSS, HTML.
- Hosting: Firebase Hosting.

## Implementación

- Angular CLI para scaffolding y builds.
- Configuración de `firebase.json` y `.firebaserc` para despliegue.

## Cómo funciona

- Onboarding: registro/inicio de sesión (si aplica).
- Gestión: creación/edición/listado con validaciones.
- Integraciones: servicios externos cuando corresponde.
