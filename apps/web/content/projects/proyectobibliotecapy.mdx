## Resumen

- Prototipo funcional para gestionar libros y usuarios desde consola.
- Incluye lista de espera para libros no disponibles.
- Código fuente: https://github.com/24BytesCo/ProyectoBibliotecaPy

## Características

- Registrar libros y usuarios; prestar y devolver libros.
- Ver catálogo y disponibilidad; ver usuarios.
- Lista de espera automática cuando no hay ejemplares.

## Stack Técnico

- Lenguajes/tecnologías: Python

## Implementación

- Módulos: `libro.py`, `usuario.py`, `biblioteca.py`, `main.py`.
- Lógica clara de dominio y flujo interactivo por consola.

## Cómo funciona

- Onboarding: registro/inicio de sesión (si aplica).
- Gestión: creación/edición/listado con validaciones.
- Integraciones: servicios externos cuando corresponde.

## Retos

- Escalabilidad y mantenibilidad del código.
- Seguridad y manejo de datos.
- Experiencia de usuario consistente.

## Mejoras futuras

- Métricas/observabilidad y pruebas más profundas.
- Automatizaciones de despliegue y calidad.
