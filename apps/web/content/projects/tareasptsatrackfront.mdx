## Resumen

- SPA para crear/categorizar tareas, asignar fechas límite y marcarlas como completadas.
- Lazy loading, interceptor para loader y comunicación entre componentes con @Input/@Output.
- Video de funcionamiento enlazado en el README.
- Código fuente: https://github.com/24BytesCo/TareasPtSatrackFront

## Características

- Módulos cargados bajo demanda (mejor rendimiento).
- Interceptor HTTP para mostrar loader durante solicitudes.
- Diseño de componentes con inputs/outputs bien definidos.

## Stack Técnico

- Lenguajes/tecnologías: TypeScript, HTML, CSS

## Implementación

- Angular CLI, estructura modular y enrutado por características.

## Cómo funciona

- Onboarding: registro/inicio de sesión (si aplica).
- Gestión: creación/edición/listado con validaciones.
- Integraciones: servicios externos cuando corresponde.
