## Resumen

- SPA Angular con enfoque en rendimiento y seguridad: carga perezosa, guards de rutas e interceptores HTTP.
- Organización modular del código para mantener escalabilidad.
- Código fuente: https://github.com/24BytesCo/PT-Front-DoubleVParthers

## Características

- Lazy loading por módulos; reducción del tiempo de carga inicial.
- Guards (auth) y roles para proteger navegación/funcionalidades.
- Interceptores para anexar JWT y gestionar loaders/errores.
- Patrones de comunicación con @Input/@Output y servicios compartidos.

## Stack Técnico

- Framework: Angular (CLI), RxJS.
- Lenguajes/tecnologías: TypeScript, SCSS, HTML, CSS.

## Implementación

- Angular CLI para scaffolding y builds.
- Estructura modular: core/shared/features, routing por dominio.
- Buenas prácticas de estilos y theming con SCSS.

## Cómo funciona

- Login → navegación a vistas restringidas (guards).
- Interceptor añade cabeceras y gestiona spinners/errores de red.
- Módulos funcionales se cargan bajo demanda.

## Retos

- Balancear seguridad/UX sin penalizar rendimiento.
- Estandarizar comunicación entre módulos y manejo de estado.

## Mejoras futuras

- Internacionalización (i18n) y accesibilidad (a11y).
- Estrategias de prefetch y PWA.
- Pruebas unitarias/e2e y pipeline CI/CD.
